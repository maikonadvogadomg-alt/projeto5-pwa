📁 Estrutura de Pastas

Crie exatamente estas pastas:

iara-pro/
├── core/
├── styles/
├── modules/
│ ├── sidebar/
│ ├── editor/
│ ├── preview/
│ ├── ai/
│ ├── mapper/
│ ├── context-menu/
│ ├── tabs/
│ ├── guide/
│ └── export/
└── index.html

Comando para criar (Linux/Mac):

mkdir -p iara-pro/{core,styles,modules/{sidebar,editor,preview,ai,mapper,context-menu,tabs,guide,export}}

Comando para criar (Windows PowerShell):

New-Item -ItemType Directory -Path iara-pro -Force; cd iara-pro; mkdir core,styles; mkdir modules; cd modules; mkdir sidebar,editor,preview,ai,mapper,context-menu,tabs,guide,export
Após criar as pastas, você terá a estrutura pronta para adicionar os arquivos!

📋 Comandos para Copiar

1. Criar pasta (Linux/Mac):

mkdir -p iara-pro/{core,styles,modules/{sidebar,editor,preview,ai,mapper,context-menu,tabs,guide,export}}

2. Entrar na pasta:

cd iara-pro

3. Criar arquivos core (Linux/Mac):

touch core/app.js core/state.js core/storage.js core/utils.js

4. Criar arquivos styles (Linux/Mac):

touch styles/theme.css styles/responsive.css

5. Criar arquivos modules (Linux/Mac):

touch modules/sidebar/sidebar.js modules/editor/editor.js modules/preview/preview.js modules/preview/preview-drag.js

6. Criar mais modules (Linux/Mac):

touch modules/ai/ai-detect.js modules/ai/ai-providers.js modules/ai/ai.js

7. Criar mapper modules (Linux/Mac):

touch modules/mapper/mapper-analyze.js modules/mapper/mapper-deps.js modules/mapper/mapper-bugs.js modules/mapper/mapper-git.js modules/mapper/mapper-bate.js modules/mapper/mapper-report.js modules/mapper/mapper.js

8. Criar últimos modules (Linux/Mac):

touch modules/context-menu/context.js modules/tabs/tabs.js modules/guide/guide.js modules/export/export.js

9. Criar index.html (Linux/Mac):

touch index.html

10. Listar tudo (verificar):

find . -type f -name "*.js" -o -name "*.css" -o -name "*.html" | sort

11. Iniciar servidor (Python 3):

python -m http.server 8000

12. Iniciar servidor (Node.js):

npx http-server

13. Iniciar servidor (PHP):

php -S localhost:8000
Clique em qualquer comando para copiar para a área de transferência!
